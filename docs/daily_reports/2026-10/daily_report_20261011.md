### 2. アプリプレビュー動画の作成 ✅

**Problem / Root Cause**:

- 1920×886 の PNG をアプリプレビュー枠に入れると「サイズ無効」になった。アプリプレビュー枠は画像ではなく動画（.mov / .m4v / .mp4）だけを受け付ける。
- この Mac の ffmpeg は x265 ライブラリが見つからず起動しない。環境を変えないため、修復はしなかった。

**Solution**:

- macOS 標準の AVFoundation（Swift）で、画像を15秒間映す静止画の動画にした。
- 仕様: 1920×886、30fps、H.264、無音の AAC 音声トラック付き。サイズ・長さ・音声トラックの有無は確認済み。

**Status**: ✅ 完了（App Store Connect 上での受け付けは未確認）
