# GoShopping

家族・グループで買い物リストを共有できるアプリです。
Full sync に対応し、複数デバイス間でリアルタイムに買い物リストや共有ToDoを更新できます。

## 主な機能

- グループで共有できる買い物リスト・ToDoリスト
- 複数デバイス間でのリアルタイム同期
- オフライン時でも利用できるローカル保存
- QRコードで簡単にグループへ招待
- グループの買い物リストを一緒に編集できるホワイトボード機能
- Freeプラン（最大3グループ・各グループ最大10人）／ Premiumプラン（上限なし、広告非表示）
